# Session handoff, 2026-09-12

Website repo. Eighteen commits, none pushed. Suite 514 passed, 0 failed.

## The pattern, which is the most useful thing here

Four separate defects this session were the same shape: **a mechanism that looks
present, reports success, and is not connected to anything.** Every one passed a
green suite. None would have been found by reading the code that appeared to do
the job.

1. **A strip in the wrong function.** The em dash strip was written into `esc()`
   and verified there. `sanaRender` is 1348 lines earlier and opens with
   `var esc = ...`, a local that shadows the global for the whole body, so the two
   could never meet. Production shipped em dashes for four days while the fix sat
   in the file. The renderer's 12 assertions all passed on the broken version, and
   so did the full suite of 371, because not one of them concerned a dash.

2. **A read with no writer.** The backend resolves a per-user timezone from
   `device_flags.timezone`. Nothing anywhere writes it: zero writers in the
   backend, no column on the Supabase profiles table, zero mentions in the app. So
   every user was silently treated as Asia/Kolkata, and a woman in New York was
   told the wrong cycle day for the 5h30m either side of midnight IST.

3. **A swallowed invoke.** The upload path discarded the thrown case with a bare
   catch and inspected the response only for status 429. supabase-js does not
   throw on a non-2xx, so every other refusal survived as a value nobody read, and
   execution fell through to a poll with no timeout. Each distinct failure
   presented as an endless spinner. The only signal was a woman not coming back.

4. **Copy asking for a reply with no reply channel.** Every failure string ends
   "tell us and we will look at it with you". The failure screen offered a retry
   and a link to the dashboard. The support address appeared five times elsewhere
   in the file and zero times on that screen.

**What catches this class:** a control of the same KIND as the thing being
measured, in the same run. A zero is evidence only when a known-positive is
non-zero beside it. Several assertions written this session were wrong on first
run and were fixed rather than loosened, twice because a character-window check
was really asserting spacing.

## What shipped

**sanaRender em dash strip**, in `dashboard.html` and in `mocks/sana-thread.html`,
with the five assertions the file never had. The shadowing local is renamed
`escaped` so "sanaRender uses esc" can no longer be a believable sentence.

**Client timezone**, `X-Client-Timezone` header on the chat request and a
`timezone` body field on both process-report payloads. Two transports on purpose:
the upload path has no live request to carry a header on.

**Upload failure surfaced as two states.** PATH 1, never enqueued, knowable
immediately, offers a retry. PATH 2, enqueued but overdue, a 25 minute bail read
from `created_at` rather than the poll clock, offers none because the job may
still land. The derivation is in the code: 6.8 min measured happy path,
`PC_LONG_MS` at 9 is a copy threshold and not a ceiling, the reaper path at ~20.5
is modelled not measured, so 25 rather than a falsely precise 21.

**Gate exits.** Both blocking gates now sign out with scope local, read the
returned error, and on failure clear the stored session directly and CONFIRM
through `getSession` before navigating. Nothing is hardcoded; the storage key is
read off the live client. All four signOut sites now read their return, and the
delete path's sign-out no longer falls into the delete's catch, where a throw used
to render a delete-FAILURE state for a deletion that had succeeded.

**Foundations and daily checklist** prose take the same dash pipe as their
siblings, with `dcEsc` kept entity-only and now guarded by a test, because
`dcToggle` matches `data-aid` by equality against a value that never passes
through an escaper.

**Landing copy.** The hero no longer claims the panel "explains" fatigue, cycle
issues and brain fog. A panel measures markers. The woman this page is written for
is the one whose tests came back normal, so she is disproportionately likely to be
the one a panel does not explain.

**Mocks untracked** and moved to `~/biowellth-mocks-approved/`, verified 13 of 13
by sha before untracking. `9081aa8` remains the provenance record.

**Session lock added**, mirroring supa rule 18, after two concurrent-write
incidents in one afternoon, the second of which checked out another branch in this
working tree mid-command and reverted every file an in-flight session had touched.
